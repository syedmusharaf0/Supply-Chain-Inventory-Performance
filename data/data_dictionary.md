# Data Dictionary

Sample dataset (synthetic, generated by `python/generate_sample_data.py`,
seed 42) modelling daily stock records for 24 SKUs across 3 regional
warehouses, 1 Jan – 30 Jun 2025. No real company data is used.

## dim_products.csv — one row per SKU
| Column | Description |
|---|---|
| sku | Product code (SKU-001 … SKU-024) |
| product_name | Product name |
| category | Electronics / FMCG / Apparel / Home Appliances / Auto Parts |
| unit_cost_sar | Unit cost in Saudi Riyal |
| unit_cost_inr | Unit cost in Indian Rupee (SAR × 22.30, approximate Nov 2026 rate) |
| supplier | Supplying vendor |
| standard_lead_time_days | Agreed/expected replenishment lead time |
| reorder_point_units | Stock level that triggers a replenishment order |
| base_daily_demand | Average daily demand used by the generator |

## fact_daily_stock.csv — one row per SKU × warehouse × day (13,032 rows)
| Column | Description |
|---|---|
| date | Record date |
| warehouse | Riyadh Central / Jeddah Hub / Dammam Hub |
| sku | Product code |
| opening_stock | Units at start of day |
| units_received | Units received from purchase orders that day |
| units_sold | Units sold/fulfilled that day |
| units_lost_sales | Demand that could not be fulfilled (demand − available stock) |
| closing_stock | Units at end of day = opening + received − sold |
| stockout_day | 1 if any demand was lost that day, else 0 |

## fact_purchase_orders.csv — one row per replenishment order (1,079 rows)
| Column | Description |
|---|---|
| order_id | PO number |
| order_date | Date the order was placed |
| sku / warehouse / supplier | What, where, from whom |
| quantity_units | Ordered quantity |
| standard_lead_time_days | Expected lead time |
| actual_lead_time_days | Actual lead time taken |
| arrival_date | order_date + actual lead time |
