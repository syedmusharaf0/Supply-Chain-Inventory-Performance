# Data Dictionary

## dim_products.csv — product master
| Column | Type | Description |
|---|---|---|
| sku | text | Stock keeping unit (unique) |
| product_name | text | Product display name |
| category | text | Electronics / Apparel / FMCG / Home & Living / Automotive / Sports |
| supplier | text | Supplying vendor |
| unit_cost_inr | decimal | Unit cost in Indian Rupees (₹) — the project's only currency |
| reorder_point | int | Stock level that triggers replenishment |

## fact_daily_stock.csv — one row per SKU per warehouse per day
| Column | Type | Description |
|---|---|---|
| date | date | Calendar day (1 Jan – 30 Jun 2025) |
| sku | text | FK to dim_products |
| warehouse_id | text | WH-MUM = Mumbai Central, WH-DEL = Delhi Hub, WH-BLR = Bengaluru Hub |
| opening_stock | int | Units available at start of day |
| units_received | int | Units received from replenishment that day |
| units_sold | int | Units sold |
| lost_sales_units | int | Demand that could not be fulfilled (stock-out) |
| closing_stock | int | opening + received − sold |

## fact_purchase_orders.csv — purchase orders
| Column | Type | Description |
|---|---|---|
| po_number | text | Unique purchase order id |
| order_date | date | Date the order was placed |
| sku | text | FK to dim_products |
| warehouse_id | text | Receiving warehouse |
| quantity_ordered | int | Units ordered |
| promised_lead_time_days | int | Supplier-promised lead time |
| actual_lead_time_days | int | Actual lead time |
| delivery_date | date | order_date + actual lead time |

**Note:** synthetic sample data generated by `python/generate_sample_data.py`
(seed 42) for demonstration — modelled on a real project structure,
no real company data.
